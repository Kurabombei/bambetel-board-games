# 🎲 Bambetel Board Games (Frontend)

A mobile-first, gamified web application (PWA) for board game enthusiasts. The platform serves as a community hub where users can track their personal board game collections, organize local or online events, and build reputation within their local gaming community.

> **Note:** This repository contains the **Frontend** application (Next.js). The Backend services (Node.js/TypeScript) are maintained in a separate repository.

## ✨ Key Features
* **Gamified UI/UX:** Highly optimized web animations and a custom component library (Material v3 principles via SCSS).
* **Collection Management:** Virtual shelves integrated with the BGG (BoardGameGeek) API.
* **Event Discovery:** Browse and join local board game sessions.
* **Activity Tracking:** Visual contribution graph (GitHub-style) for user gaming activity.

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Library:** React
* **Styling:** SCSS Modules (No Tailwind), Custom MUI v6 / Mantine integration
* **Type Safety:** Strict TypeScript
